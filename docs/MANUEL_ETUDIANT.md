# Manuel Utilisateur — Portail Étudiant

Bienvenue sur **DocScolaire**, la plateforme numérique officielle permettant de demander et télécharger vos documents scolaires certifiés (attestations de réussite, certificats de scolarité, relevés de notes) en quelques clics.

---

## 1. Accéder au Portail de votre Établissement

Votre établissement dispose d'une adresse personnalisée sous la forme :
```
https://plateforme.com/portal/[CODE_DE_VOTRE_ECOLE]
```
*Exemple : pour l'École Nationale Supérieure (code `ENS-2026`), l'adresse est `https://plateforme.com/portal/ENS-2026`.*

Si vous ne connaissez pas l'adresse directe, rendez-vous sur la page d'accueil principale `https://plateforme.com` et saisissez le code de votre école dans le champ prévu à cet effet.

---

## 2. Installer l'Application sur votre Téléphone (PWA)

DocScolaire fonctionne comme une véritable application mobile sans rien télécharger sur l'App Store ou le Google Play Store :

### Sur Android (Google Chrome)
1. Ouvrez le lien de votre école dans Chrome.
2. Appuyez sur les trois petits points en haut à droite.
3. Sélectionnez **« Ajouter à l'écran d'accueil »** (ou « Installer l'application »).
4. Une icône DocScolaire apparaît sur votre écran de téléphone !

### Sur iPhone / iPad (Safari)
1. Ouvrez le lien de votre école dans le navigateur Safari.
2. Appuyez sur le bouton de partage (icône avec un carré et une flèche vers le haut).
3. Faites défiler vers le bas et sélectionnez **« Sur l'écran d'accueil »**.
4. Appuyez sur **« Ajouter »**.

---

## 3. Connexion à votre Espace Étudiant

1. Sur la page d'accueil de votre école, saisissez votre **Matricule** (ou votre email étudiant) et votre **mot de passe**.
2. Cliquez sur **« Se connecter »**.
3. Vous arrivez directement sur votre tableau de bord personnel affichant votre nom, votre filière et votre niveau d'études.

---

## 4. Demander un Document Officiel

1. Dans votre tableau de bord, descendez jusqu'à la section **« Demander un document »**.
2. Dans la liste déroulante, sélectionnez le document souhaité (ex: *Attestation de Réussite*).
3. Cliquez sur le bouton **« Demander le document »**.
4. Deux scénarios possibles :
   - **Délivrance immédiate (Automatique)** : le document est généré en quelques secondes et apparaît avec un bouton vert **« Télécharger le PDF »**.
   - **Validation administrative requise** : votre demande passe en statut **« En attente de validation »**. Vous recevrez un email dès que l'administration aura validé votre demande.

---

## 5. Télécharger et Vérifier votre Document

1. Cliquez sur **« 📥 Télécharger le PDF »** à côté du document généré.
2. Le fichier PDF officiel s'ouvre sur votre appareil.
3. Chaque document contient :
   - Le sceau et les informations officielles de votre établissement.
   - Vos résultats et informations académiques certifiées.
   - Un **QR code de vérification unique** en bas de page.
4. Toute personne (employeur, ambassade, université étrangère) peut scanner ce QR code avec son smartphone pour vérifier instantanément que le document est authentique et n'a pas été falsifié.

---

## 6. Mot de Passe Oublié ?

1. Sur la page de connexion, cliquez sur le lien **« Mot de passe oublié ? »**.
2. Saisissez votre adresse email étudiant.
3. Vous recevrez instantanément un lien sécurisé valable 60 minutes.
4. Cliquez sur le lien pour définir un nouveau mot de passe d'au moins 8 caractères.
